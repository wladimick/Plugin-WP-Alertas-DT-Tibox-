# Checklist pendiente con cliente

## Comercial

- [ ] Precio anual definitivo.
- [ ] Confirmar si el precio incluye IVA.
- [ ] Un solo plan o varios planes.
- [ ] Alcance exacto de la prueba gratuita.
- [ ] Una prueba por correo, RUT o persona.
- [ ] Política de devolución.
- [ ] Avisos antes del fin de prueba.
- [ ] Avisos antes del vencimiento anual.
- [ ] Confirmar que la renovación seguirá siendo manual.
- [ ] Definir desde cuándo comienza la prueba para suscriptores históricos que activen su cuenta.

## Cuenta y perfil

- [ ] Campos obligatorios: nombre, RUT, teléfono, empresa.
- [ ] Persona natural o empresa.
- [ ] Validación de RUT.
- [ ] Cambio de correo.
- [ ] Eliminación de cuenta.
- [ ] Textos de términos y privacidad.
- [ ] Consentimiento para email y WhatsApp.
- [ ] Tratamiento de comunicaciones operacionales después del opt-out.
- [ ] Texto definitivo del correo de activación para suscriptores históricos.
- [ ] Campaña o invitación inicial para activar cuentas existentes.

## Pago

- [ ] Webpay Plus directo o Membrezia.
- [ ] Código de comercio y contrato Transbank.
- [ ] Cuenta bancaria receptora.
- [ ] Flujo de pago rechazado o abandonado.
- [ ] Anulación y devolución.
- [ ] Conciliación administrativa.
- [ ] Responsable de soporte de pagos.

## Nueva razón social

- [ ] Nombre y RUT.
- [ ] Giro.
- [ ] Inicio de actividades.
- [ ] Representante legal.
- [ ] Cuenta bancaria.
- [ ] Certificado digital.
- [ ] Dominio/correos comerciales.

## Documentos tributarios

- [ ] Boleta afecta, exenta o factura.
- [ ] Datos obligatorios del receptor.
- [ ] Tratamiento de IVA.
- [ ] Integración y plan Lioren.
- [ ] Ambiente de pruebas.
- [ ] Notas de crédito.
- [ ] Envío y almacenamiento de PDF/XML.

## Membrezia

- [ ] Plan actual de la cliente.
- [ ] API disponible.
- [ ] Webhooks disponibles.
- [ ] Segunda razón social.
- [ ] Integración con Lioren.
- [ ] Links de pago y conciliación.
- [ ] Posibilidad de usar WordPress como portal y Membrezia solo como cobro.

## Antes de producción

- [ ] Staging separado.
- [ ] Verificación de correo para registros nuevos.
- [ ] Validar en staging la activación segura de suscriptores históricos.
- [ ] Rate limiting adicional de login y recuperación.
- [ ] Revisión legal.
- [ ] Pruebas de seguridad.
- [ ] Respaldos y plan de reversa.
- [ ] Monitoreo de pagos y DTE.
